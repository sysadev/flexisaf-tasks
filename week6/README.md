# Week 6 Task

## Description
This assignment covers the fundamental SQL commands using PostgreSQL. It includes queries to create a table named flexi, insert a new record, update an existing record, and delete a record.

## Files
- `queries.sql`: Contains the raw SQL commands to execute the required operations.

## How to Run
1. Open your PostgreSQL command line tool (psql) or your preferred database manager like `pgAdmin`.
2. Connect to your database.
3. Copy and paste the queries from the `queries.sql` file to execute them, or run the file directly using:
   ```
   \i queries.sql
   ```
