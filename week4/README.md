# Week 4 Task

## Description
This assignment demonstrates how to use the modern Java `java.time` API. It contains three simple utilities:
1. Reporting the length of each month for a specific year.
2. Listing all Mondays for a specific month in the current year.
3. Checking if a given date falls on Friday the 13th.

## Files
- `DateTasks.java`: The main program containing all three date-checking methods.

## How to Run
1. Open your terminal in this folder.
2. Compile the code:
   ```
   javac DateTasks.java
   ```
3. Run the program:
   ```
   java DateTasks
   ```
