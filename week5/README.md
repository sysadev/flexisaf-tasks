# Week 5 Task

## Description
This assignment demonstrates how to define, throw, and catch a custom exception in Java. It creates a specific `InvalidAgeException` which is triggered when an invalid age is passed to a method.

## Files
- `InvalidAgeException.java`: The definition of the custom exception class.
- `CustomExceptionDemo.java`: The main program that throws and catches the custom exception inside a try-catch block.

## How to Run
1. Open your terminal in this folder.
2. Compile both files:
   ```
   javac *.java
   ```
3. Run the demo:
   ```
   java CustomExceptionDemo
   ```

## Expected Output
```
Caught Custom Exception: Age is strictly under 18. Access denied.
```
